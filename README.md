# Scientific-Calculator


A feature-rich desktop scientific calculator built using Python and Tkinter.
It supports expression parsing, scientific operations, themes, history tracking, memory functions, and has been packaged into a Windows executable using PyInstaller.

---

🚀 Features

- Basic arithmetic operations (+, -, ×, ÷)
- Scientific functions (sin, cos, tan, log, factorial, etc.)
- Expression parser with operator precedence
- Multiple themes (Light, Dark, etc.)
- Calculation history with timestamps
- Memory functions (M+, MR, MC)
- Keyboard support
- Error handling for invalid inputs
- Windows desktop executable support

---

🧠 Tech Stack

- Python
- Tkinter (GUI)
- Math module
- PyInstaller (for packaging)
